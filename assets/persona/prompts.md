# 배근이 상황별 이미지 프롬프트

Gemini 같은 이미지 생성 도구에 `baegun.jpg`를 **참고 이미지로 함께 올리고** 아래 프롬프트를 붙여넣는다.
만든 이미지는 이 폴더에 표의 파일명으로 저장한다.

## 공통 (모든 프롬프트 앞에 붙인다)

```text
첨부한 캐릭터와 똑같은 인물로 그려줘. 같은 웹툰 그림체, 같은 얼굴·체형·검은 뿔테 안경·떡진 앞머리,
흰 반팔 교복 셔츠와 남색 넥타이. 늘 식은땀을 흘리고 잔뜩 움츠린 소심한 고등학생. 배경은 학교 복도나 교실, 정사각형 1:1.
글자나 말풍선은 넣지 마.
```

## 상황별

| 파일명 | 쓰는 곳 | 프롬프트 |
|---|---|---|
| `generate.png` | 팀 편성 결과 | 두 손으로 출석부 같은 종이를 들고 안경을 치켜올리며 긴장한 채 무언가를 발표하려는 모습. 식은땀, 살짝 떨리는 손 |
| `split.png` | 분배 완료 | 친구들의 등을 밀며 교실 문 쪽으로 허둥지둥 안내하는 모습. 숨이 차서 헉헉대고 땀이 튄다 |
| `assemble.png` | 모으기 완료 | 땀범벅이 된 채 지친 표정으로 엄지를 들어 보이는 모습. 손에 빵과 우유를 들고 있다 |
| `error.png` | 오류·거절 안내 | 두 손을 모으고 고개를 숙여 사과하는 모습. 눈물이 맺히고 안경이 흘러내린다 |
| `stale.png` | 만료된 버튼 | 구겨진 종이를 들고 당황해서 눈이 동그래진 모습. 머리 위에 물음표 대신 땀방울 |
