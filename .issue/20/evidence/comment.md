## #20 작업 리포트

**브랜치** `feat/20-end-button-auto-close` · 커밋 `bba8ee8`(구현) `0b709b9`(문서)

### 바뀐 점
- 분배 결과 메시지에 **`[종료하기]`** 버튼을 추가했습니다. 누르면 아무도 옮기지 않고 판만 끝냅니다.
- 이전 판이 남아 있는 로비에서 `[팀 분배]`를 누르면 **이전 판을 자동으로 끝내고** 새 판을 시작합니다. 모으기 없이 바로 `/팀짜기` → `[팀 분배]`가 됩니다.
- 판이 끝날 때 팀 채널은 이렇게 처리합니다.
  - 빈 채널은 바로 삭제합니다.
  - 사람이 남은 채널은 이름을 `N팀 (종료)`로 바꾸고, 비는 즉시 삭제합니다.
  - 채널이 모두 지워지면 판 기록도 삭제합니다.
- 진행 중인 판의 빈 채널 1분 정리 규칙은 그대로입니다.
- DB에 판 상태 `ended`를 추가했습니다. 예전 DB는 시작할 때 데이터를 보존한 채 자동으로 마이그레이션됩니다.

### 예외 처리
- 끝난 판의 `[모으기]`/`[종료하기]`/`/모으기`는 그 판의 사람들을 옮기지 않습니다(버튼은 정리합니다).
- 끝난 판에 남은 오래된 `[팀 분배]` 버튼은 지금 진행 중인 판을 건드리지 않습니다.
- 종료할 때 지우지 못한 빈 채널은 다시 시도해서 지웁니다.
- 이전 팀 채널에 남은 사람은 로비에 없으므로 처음부터 새 편성에 들어가지 않습니다.
