### 바뀐 점
- `/구인 카테고리:(일반|경쟁) 설명:` — 음성채널에 있어야 실행. 첨부 이미지 형식의 임베드(팀원 모집 / @실행자 님이 팀원 모집 중입니다. / 카테고리 / 채널명 / 멤버 `3명 / 4명` / 설명) + **[음성채널 입장]** 링크 버튼
- `/구직 카테고리:(일반|경쟁) 설명:` — 팀 구함 임베드 + **[구인하기]** 버튼
- **[구인하기]** — 음성채널에 있는 사람이 누르면 그 채널의 초대링크(1시간 유효)를 구직자 DM으로 전송
  - 음성채널 밖 / 구직자 본인 / DM 차단 → 누른 사람에게만 안내
  - 봇에 초대 만들기 권한이 없으면 채널 링크로 대신 전송 (서버 멤버는 바로 입장 가능)
- 인원 제한이 없는 채널은 멤버를 `3명` 으로만 표시
- 문서: spec / tech(권한 표) / setup(초대 권한값 `17826833`) / README / INDEX
