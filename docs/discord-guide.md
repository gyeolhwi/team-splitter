# 디스코드 안내 문구

기능이 바뀌면 `docs/spec.md`와 함께 이 문구도 고친다. 말투 기준은 `docs/persona.md`.

## 1. 이용안내 채널 게시글

이용안내 채널에 그대로 붙여넣는다(약 1,100자, 메시지 한 개 2000자 제한 안). 이미지는 `assets/persona/avatar-1024.jpg`를 함께 첨부한다.

```markdown
# :bus: 셔틀봇 배근이 이용 안내

히, 히이익?! (파들파들) 저, 저는 내전 팀을 짜 드리는 셔틀봇 **배근이**라능...!
음성채널에 모이신 분들을 랜덤으로 팀을 나누고, 팀 채널로 모셔다 드리고, 게임이 끝나면 다시 모셔 오겠다능...! (안경을 슥 치켜올리며)

## :pushpin: 사용 방법

① 내전할 음성채널(로비)에 다 같이 들어가 주시라능
② 채팅창에 `/팀짜기` 입력
③ 편성 결과 확인 후, 판을 연 분이 `팀 분배` 버튼 선택 → 팀 채널 생성·이동
④ 게임이 끝나면 `모으기` 버튼 또는 `/모으기` → 로비로 집합, 팀 채널 삭제

:satellite: 제가 멀쩡한지 궁금하시면 `/ping` 불러 주시라능... 대답이 없으면 쓰러진 거라능...! (파들파들)

## :gear: 옵션 (`/팀짜기` 뒤에 붙인다능)

- `팀수:3` → 3팀으로 나누기 (안 쓰시면 2팀이라능)
- `인원수:5` → 한 팀에 5명씩, 남는 분은 미지정
- `팀수:2 인원수:5` → 딱 2팀 × 5명까지만
- `제외:@관전자` → 편성에서 빼기 (여러 분은 이어서 멘션, 결과에 따로 표시된다능)

## :warning: 이용 시 주의사항

- 편성 대상은 로비에 계신 분들이라능. 음소거하신 분도 포함, 봇은 자동으로 빠진다능
- 2, 2명 이상 계셔야 팀을 나눌 수 있다능...!
- 편성 결과는 **10분** 동안만 유효하고, 다시 편성하면 이전 버튼은 무효라능
- 분배는 판을 연 분만, 모으기는 판을 연 분이나 참가자만 할 수 있다능
- 로비 하나에 진행 중인 판은 하나뿐이라능. 새 판은 모으기 후에 부탁드린다능
- 팀 채널이 비면 1분 뒤 그 채널은 제가 치워 두겠다능 (호다닥)

## :white_check_mark: 한눈에 보기

:video_game: 내전 참가자
로비 음성채널 입장
→ `/팀짜기`
→ `팀 분배` 으로 팀 채널 이동
→ 게임 끝나면 `모으기`

:bulb: 결과가 마음에 안 드시면 `/팀짜기`를 다시 불러 주시라능... 몇 번이든 새로 짜 오겠다능...! (식은땀 뻘뻘) 고, 고멘나사이...!
```

## 2. 개발자 포털 · 일반 정보 · 설명 (최대 400자)

봇 프로필의 "자기소개"로 보인다(약 230자).

```
히, 히이익?! (파들파들) 내전 팀 셔틀봇 배근이라능...!
음성채널에 모이신 분들을 랜덤으로 팀을 나누고, 팀 채널로 모셔다 드리고, 끝나면 다시 모셔 오겠다능...! (안경을 슥 치켜올리며)

/팀짜기 → 팀 편성
[팀 분배] → 팀 채널로 이동
[모으기] → 로비로 집합
/ping → 배근이 상태 확인

• 팀 수·팀당 인원 지정
• 관전자 제외
• 빈 팀 채널은 제가 치워 두겠다능... (호다닥)
```
