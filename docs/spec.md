# 기능 명세

## 1. 목적과 목표

**목적:** 내전할 때 팀을 짜고, 채널을 나누고, 다시 모으는 일을 손으로 하지 않기 위해 만든다.

**목표:** 음성채널 하나(로비)에 모인 인원을 랜덤으로 팀 편성하고, 팀별 음성채널을 만들어 분배한다. 게임이 끝나면 로비로 다시 모은다.

- 봇을 추가한 서버라면 어디서든 동작한다. 웹 페이지나 로그인은 없다.
- 한 서버에서 여러 판을 동시에 돌릴 수 있다. 단, 로비 하나당 진행 중인 판은 하나다.
- 목표는 **단순하고 고장 나지 않는 것**이다.

## 2. 흐름

```
/팀짜기 ──> 편성 결과 표시 ──[팀 분배]──> 팀 채널 생성 + 분배
                                                        │
      로비 <──────────[모으기] / /모으기──────────────┘
                  (팀 채널 인원 → 로비, 팀 채널 삭제, 판 종료)
```

## 3. 명령어와 버튼

| 항목 | 누가 | 동작 |
|---|---|---|
| `/팀짜기` | 누구나 | 내가 있는 음성채널(로비) 인원으로 바로 편성하고 결과를 보여준다 |
| **[팀 분배]** | 판을 연 사람 | 팀 채널을 만들고 팀원을 분배한다 |
| **[모으기]** / `/모으기` | 판을 연 사람, 참가자 | 로비로 모으고 팀 채널을 삭제한 뒤 판을 끝낸다 |
| `/ping` | 누구나 | 봇이 정상 동작하는지 점검 결과를 보여준다 |

### `/팀짜기` 옵션

| 옵션 | 설명 |
|---|---|
| `팀수:N` | 팀 수 (1~25) |
| `인원수:N` | 팀당 인원 (1~25) |
| `제외:@a @b` | 뺄 사람. 멘션을 이어 쓴다 |

- 편성 결과에는 팀별 인원, `미지정`(팀에 못 들어간 사람), `제외`(`제외` 옵션으로 뺀 사람)를 각각 따로 보여준다. 없으면 그 줄을 생략한다.
- 결과가 마음에 들지 않으면 명령을 다시 친다. 다시 섞기 버튼은 없다.
- 같은 로비에서 다시 치면 이전 결과의 [팀 분배]은 무효가 된다. 편성 결과는 10분 동안만 유효하다.
- 무효가 된 버튼은 누르는 순간 메시지에서 지우고, 누른 사람에게만 안내한다.
- 편성 대상이 2명 미만이면 거절한다.
- 음성채널에 없는 상태에서 치거나, 진행 중인 판의 팀 채널에서 치면 거절한다.

### `/ping` 점검 항목

| 항목 | 내용 | 이상으로 보는 기준 |
|---|---|---|
| 디스코드 연결 | 게이트웨이 하트비트 지연(ms). 켜진 직후에는 "측정 중" | 1000ms 초과 |
| 명령 수신 | 명령을 친 순간부터 봇이 받기까지(ms) | 표시만 한다 |
| 가동 시간 | 마지막 재시작 이후 시간 | 표시만 한다 |
| 저장소(DB) | SQLite에 간단한 쿼리가 되는지 | 쿼리 실패 |

- 이상이 없으면 "정상 운행 중", 있으면 어느 항목이 이상한지 먼저 적는다.
- 봇이 꺼져 있으면 응답 자체가 없다(디스코드가 "애플리케이션이 응답하지 않았습니다"를 띄운다).

### 메시지 공개 범위

| 메시지 | 보이는 사람 |
|---|---|
| 편성 결과, 분배 결과, 모으기 결과, `/ping` 점검 결과 | 채널 전체. 참가자가 [모으기]을 누를 수 있어야 한다 |
| 오류·거절 안내 | 명령을 친 사람만 (ephemeral) |

## 4. 팀 편성 규칙

**편성 대상:** 로비에 지금 있는 사람 중에서 봇 계정과 `제외`을 뺀다. 음소거한 사람은 포함한다.

| 입력 | 규칙 | 예시 (10명) |
|---|---|---|
| 없음 | 2팀 균등 | 5 / 5 (7명이면 4 / 3) |
| `팀수:K` | K팀에 균등하게 나눈다 | K=3 → 4 / 3 / 3 |
| `인원수:S` | S명씩 나누고 남는 사람은 미지정 | S=4 → 4 / 4, 미지정 2 |
| `팀수:K` + `인원수:S` | 딱 K팀 × S명까지. 인원이 모자라면 앞 팀부터 채운다 | 3×2 → 2 / 2 / 2, 미지정 4<br>3×4 → 4 / 4 / 2 |

- **미지정:** 팀에 들어가지 못한 사람이다. 이동시키지 않고 로비에 남긴다.
- 빈 팀은 만들지 않는다. 팀이 0개가 되면 몇 명이 부족한지 안내한다.
- 섞을 때는 Fisher–Yates 방식을 쓰고, 난수는 `crypto.randomInt`로 뽑는다.

## 5. 동작 상세

### 팀 분배

1. 이 로비에 진행 중인 판이 있으면 거절한다. 여러 명이 동시에 누르면 먼저 누른 쪽만 성공한다.
2. 로비와 같은 카테고리에 `1팀`, `2팀`… 채널을 **전부 먼저** 만든다. 도중에 실패하면 만든 채널을 지우고 끝낸다.
3. **지금 로비에 있는** 팀원만 자기 팀 채널로 한 명씩 옮긴다. 옮기지 못한 사람은 결과에 표시한다.
4. 결과 메시지에 **[모으기]** 버튼을 단다.

### 모으기

1. 로비가 지워졌으면 팀 채널과 같은 카테고리에 `로비` 음성채널을 새로 만들고 그곳으로 모은다. 만들지 못하면 에러만 안내하고 아무것도 하지 않는다.
2. 팀 채널에 **지금 있는 사람 전부**를 로비로 옮긴다. 참가자인지 관전자인지 가리지 않는다.
3. 비어 있는 팀 채널을 지우고 판을 끝낸다. 다음 판은 새로 시작한다.

## 6. 안전장치 (고장 방지)

1. **실행하는 순간의 실제 상태를 본다.** 누가 어디 있는지는 버튼을 누르는 순간 다시 확인한다. 그래서 사람들이 채널을 오가도 꼬이지 않는다.
2. **봇이 만든 채널만, 비어 있을 때만 지운다.** 채널은 ID로만 찾는다. 사람이 있는 채널을 지우면 그 사람의 음성 연결이 끊기기 때문에 지우지 않는다.
3. **빈 팀 채널은 채널별로 자동 정리된다.** 팀 채널 하나가 비면 1분 뒤 다시 확인하고, 여전히 비어 있으면 그 채널만 지운다. 판의 팀 채널이 모두 지워지면 판을 끝낸다. 1분 안에 누가 다시 들어오면 지우지 않고, 지우지 못한 채널은 다음에 비었을 때 다시 시도한다. 봇이 재시작된 경우에도 시작할 때 한 번 점검한다.

## 7. 알려진 제약

- **재시작하는 동안 응답하지 않는다:** 업데이트 배포나 서버 재부팅 중 몇 초 동안은 명령과 버튼이 동작하지 않는다. 진행 중인 판과 편성 결과는 저장되어 있어서 재시작 뒤 그대로 이어진다.
- **모으기 직후 몇 초 사이에 팀 채널에 새로 들어온 사람**은 채널이 지워지면서 음성 연결이 끊길 수 있다.
