# 셔틀봇 (배근이)

<img src="assets/persona/thumb-256.png" width="120" align="right" alt="배근이">

디스코드 내전용 팀 편성 봇입니다.
음성채널에 모인 사람들을 랜덤으로 팀을 나누고, 팀별 음성채널로 옮겨 주고, 게임이 끝나면 다시 한곳으로 모아 줍니다.
채널을 만들고 사람을 옮기는 귀찮은 일은 소심한 빵셔틀 **배근이**가 허둥지둥 대신 해 줍니다.

## 빠른 시작

1. 내전할 **음성채널(로비)** 에 다 같이 들어갑니다.
2. 채팅창에 **`/팀짜기`** 를 입력합니다.
3. 편성 결과를 보고, 판을 연 사람이 **`[팀 분배]`** 버튼을 누릅니다. 팀 채널(`1팀`, `2팀`…)이 생기고 팀원이 자동으로 옮겨집니다.
4. 게임이 끝나면 **`[모으기]`** 버튼이나 **`/모으기`** 를 씁니다. 모두 로비로 돌아오고 팀 채널은 지워집니다.

```
로비 입장 → /팀짜기 → [팀 분배] → 🎮 게임 → [모으기]
```

결과가 마음에 안 들면 `/팀짜기`를 다시 치면 됩니다. 몇 번이든 새로 짭니다.

## 명령어와 버튼

| 명령어 · 버튼 | 누가 | 하는 일 |
|---|---|---|
| `/팀짜기` | 누구나 | 지금 있는 음성채널 인원으로 랜덤 팀을 편성합니다 |
| `[팀 분배]` 버튼 | 판을 연 사람 | 팀 채널을 만들고 팀원을 옮깁니다 |
| `[모으기]` 버튼 · `/모으기` | 판을 연 사람, 참가자 | 로비로 모으고 팀 채널을 지운 뒤 판을 끝냅니다 |
| `/ping` | 누구나 | 배근이가 정상 운행 중인지 확인합니다 |

### `/팀짜기` 옵션

옵션은 모두 선택입니다. 아무것도 안 쓰면 **2팀으로 균등하게** 나눕니다.

| 옵션 | 뜻 | 예시 (10명일 때) |
|---|---|---|
| `팀수:N` | N팀으로 균등하게 나눕니다 | `팀수:3` → 4 / 3 / 3 |
| `인원수:N` | 한 팀에 N명씩, 남는 사람은 미지정 | `인원수:4` → 4 / 4, 미지정 2 |
| `팀수:N 인원수:M` | 딱 N팀 × M명까지만 | `팀수:2 인원수:3` → 3 / 3, 미지정 4 |
| `제외:@이름` | 편성에서 뺍니다. 여러 명은 멘션을 이어 씁니다 | `제외:@관전자1 @관전자2` |

- **미지정**: 인원이 남아 팀에 못 들어간 사람입니다. 로비에 그대로 남습니다.
- **제외**: `제외` 옵션으로 직접 뺀 사람입니다. 결과에 따로 표시됩니다.

자세한 편성 규칙은 [기능 명세 · 팀 편성 규칙](docs/spec.md#4-팀-편성-규칙)에 있습니다.

## 결과 화면

`/팀짜기 제외:@관전자` 를 쳤을 때:

```
히, 히이익?! (파들파들) 파, 팀 편성 퀘스트 결과라능...! · 🔊 내전 로비

1팀 (2명) @선영 @현주
2팀 (2명) @갤만 @동필
미지정 (1명) @철수
제외 (1명) @관전자

(안경을 슥 치켜올리며) @방장님이 팀 분배를 누르시면 바, 바로 팀 채널로 모셔다 드리겠다능...!
                                                          [팀 분배]
```

`/ping` 을 쳤을 때:

```
헉, 헉... (안경을 슥 치켜올리며) 배, 배근이 정상 운행 중이라능...! 언제든 불러 주시라능...!

디스코드 연결 42ms · 명령 수신 85ms
가동 시간 4일 2시간 5분
저장소(DB) 정상
```

`/ping`에 아무 대답이 없으면 봇이 꺼진 상태입니다. 운영자에게 알려 주세요.

## 알아 두면 좋은 것

- **편성 대상**: 로비에 지금 있는 사람입니다. 음소거한 사람도 포함되고, 봇은 자동으로 빠집니다.
- **최소 인원**: 2명 이상 있어야 팀을 나눌 수 있습니다.
- **유효 시간**: 편성 결과는 **10분** 동안만 유효합니다. 다시 편성하면 이전 결과의 버튼은 무효가 됩니다.
- **한 로비에 한 판**: 진행 중인 판이 있으면 먼저 모으기를 해야 새 판을 시작할 수 있습니다.
- **빈 채널 자동 정리**: 팀 채널이 비면 **1분 뒤 그 채널을 자동으로 지웁니다.** 1분 안에 다시 들어오면 지우지 않습니다. 팀 채널이 모두 지워지면 판이 끝납니다.
- **로비가 사라져도 괜찮습니다**: 모으기 때 원래 로비가 없으면 같은 카테고리에 `로비` 채널을 새로 만들어 모읍니다.

## 자주 묻는 질문

<details>
<summary><b>결과가 마음에 안 들어요</b></summary>

`/팀짜기`를 다시 치세요. 새 결과가 나오고 이전 결과의 `[팀 분배]` 버튼은 무효가 됩니다.
</details>

<details>
<summary><b>"음성채널에 안 계신다"고 나와요</b></summary>

`/팀짜기`는 **내가 들어가 있는 음성채널** 인원으로 편성합니다. 먼저 로비 음성채널에 들어간 뒤 명령을 쳐 주세요.
</details>

<details>
<summary><b>[팀 분배] 버튼을 눌렀는데 안 돼요</b></summary>

분배는 **판을 연 사람(`/팀짜기`를 친 사람)만** 할 수 있습니다. 10분이 지났거나 더 최신 편성이 있으면 버튼이 사라집니다. 이럴 때는 `/팀짜기`를 다시 쳐 주세요.
</details>

<details>
<summary><b>모으기를 안 하고 다들 나갔어요</b></summary>

괜찮습니다. 빈 팀 채널은 1분 뒤 배근이가 알아서 지우고 판도 끝냅니다.
</details>

<details>
<summary><b>명령어가 안 보여요</b></summary>

디스코드 앱을 완전히 껐다 켜 주세요. 명령어가 바뀐 직후에는 반영까지 최대 1시간이 걸릴 수 있습니다.
</details>
